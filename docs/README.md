# Documentation

The documentation of the Klyroo hub, grouped by the kind of help each page gives. For a short overview of the ecosystem, the packages and the installation commands, start from the [repository README](../README.md).

## Tutorial

- [Getting started](getting-started.md): install the packages, query data headless, then build a Blazor page with a stat card, a data list and a form drawer.

## How-to guides

- [Guides](guides.md): register single libraries, share options with the WebAssembly client, find the owner of a component, test with xUnit and bUnit, drive a form from an agent, connect the MCP server, use the templates, publish with NativeAOT, and run the site from source.

## Reference

- [API reference](api-reference.md): every public type and member of `Klyroo.Stack.Core` and `Klyroo.Stack`, generated from the XML documentation.
- [Platforms](platforms.md): render modes, .NET MAUI Blazor Hybrid, NativeAOT and trimming, with what has and has not been verified.
- [FAQ](faq.md): troubleshooting, known limitations and common questions.
- [Benchmarks](benchmarks.md): measured timings and assembly sizes of the headless engines, with the command that reproduces them.
- [MCP server package page](../src/Klyroo.Stack.Mcp/README.md): tools, prompts, resources, options and client configuration.

## Explanation

- [Concepts](concepts.md): how the hub, the `.Core` and Blazor packages and the registration call fit together, how the MCP bundle is built, and the design decisions behind them.
